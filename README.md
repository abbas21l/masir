# مسیر — Learning Path Generator

اپلیکیشن Next.js برای ساخت مسیر یادگیری با Claude API.

## نصب محلی (اختیاری، برای تست قبل از دیپلوی)

```bash
npm install
```

یه فایل بساز به اسم `.env.local` توی روت پروژه:
```
ANTHROPIC_API_KEY=sk-ant-...
```

بعد:
```bash
npm run dev
```

باز کن: http://localhost:3000

---

## دیپلوی روی Vercel (قدم‌به‌قدم)

### قدم ۱: بردن کد روی GitHub

۱. یه ریپازیتوری جدید توی GitHub بساز (خصوصی یا عمومی، فرقی نداره) — مثلاً اسمش رو بذار `masir`

۲. توی همین پوشه که این فایل‌ها هست، این دستورات رو بزن:
```bash
git init
git add .
git commit -m "اولین نسخه"
git branch -M main
git remote add origin https://github.com/USERNAME/masir.git
git push -u origin main
```
(به‌جای `USERNAME` اسم کاربری خودت رو بذار)

### قدم ۲: وصل‌کردن به Vercel

۱. برو [vercel.com](https://vercel.com)، با GitHub لاگین کن

۲. دکمه‌ی **Add New → Project**

۳. ریپازیتوری `masir` رو انتخاب کن → **Import**

۴. توی بخش **Environment Variables**، این رو اضافه کن:
   - Name: `ANTHROPIC_API_KEY`
   - Value: کلید واقعی خودت (`sk-ant-...`)

۵. دکمه‌ی **Deploy** رو بزن — چند دقیقه طول می‌کشه

### قدم ۳: وصل‌کردن ساب‌دامین

۱. توی پروژه‌ت روی Vercel، برو **Settings → Domains**

۲. بنویس `learn.abbasramezani.com` → **Add**

۳. Vercel یه رکورد DNS بهت نشون می‌ده (چیزی شبیه `CNAME → cname.vercel-dns.com`)

۴. برو cPanel دامنه‌ات → **DNS Zone Editor** → همون رکورد رو با `Name: learn` اضافه کن

۵. چند دقیقه تا چند ساعت صبر کن تا DNS پخش بشه. Vercel خودش وضعیت رو نشون می‌ده (سبز = وصل شد)

## ساختار پروژه

```
app/
  layout.tsx          ← تنظیمات RTL و فونت
  page.tsx             ← کل UI (فرم، لودینگ، نتیجه)
  globals.css          ← استایل‌ها + طراحی «مسیر/ردِ» امضادار
  api/generate/route.ts ← تماس با Claude API
```

## کش کردن مسیرها (اختیاری ولی پیشنهادی)

اگه توی Vercel یه دیتابیس KV بسازی و به این پروژه وصل کنی (Storage → Create Database → KV)، از این به بعد:
- هر موضوع + سطحی که یه‌بار ساخته بشه، ۹۰ روز ذخیره می‌مونه
- دفعه‌ی بعد که کسی همون موضوع رو با همون سطح بخواد، **بدون تماس با Claude API** همون نتیجه‌ی قبلی نشون داده می‌شه
- سریع‌تر برای کاربر، ارزون‌تر برای تو

**بدون این تنظیم هم اپ کار می‌کنه** — فقط کش نداره، هر بار API صدا زده می‌شه. یعنی می‌تونی الان بدون KV دیپلوی کنی، بعداً هر وقت خواستی اضافه‌اش کنی.

## نکات مهم

- **بدون دیتابیس:** ذخیره‌سازی مسیرها فقط توی `localStorage` مرورگر خود کاربره. اگه کاربر مرورگر عوض کنه یا کش پاک کنه، مسیرهاش از دست می‌ره. برای فاز بعد (با لاگین)، باید یه دیتابیس مثل Supabase اضافه بشه.
- **هزینه‌ی API:** هر بار که کسی یه مسیر می‌سازه، یه تماس با Claude API انجام می‌شه و هزینه داره. فعلاً محدودیت نرخ (rate limit) نداره — اگه ترافیک بالا رفت، باید اضافه بشه.
- **مدل استفاده‌شده:** `claude-sonnet-5` — اگه خواستی مدل ارزون‌تر یا سریع‌تر (مثل Haiku) رو امتحان کنی، توی `app/api/generate/route.ts` خط `model:` رو عوض کن.
